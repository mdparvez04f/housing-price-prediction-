Housing Price Prediction

This project predicts housing prices using Machine Learning techniques in Python.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Joblib

Model Used

- Random Forest Regressor

Features

- Data preprocessing
- Missing value handling
- Feature scaling
- Categorical data encoding
- Model training and prediction

How to Run

1. Install the required libraries.
2. Place the dataset file ("housing.csv") in the project folder.
3. Run:

python main.py

The model will train and generate predictions.
